# Data-Projects-Hackathon_3-25-26

This project builds a citation prediction pipeline for scientific papers. The task is to estimate whether a source paper is likely to cite a target paper, using metadata, text similarity and citation-graph information.

The notebook follows the full path from raw data inspection to model interpretation. The central idea is not only to obtain a good classifier, but to keep the prediction setting temporally coherent: the model should rely on information that could reasonably be known before or at the publication time of the source paper.

## Data Visualization and Processing

The first part of the work focuses on understanding the raw data before modeling. The dataset contains scientific papers with titles, abstracts, authors, venues, document types, years and references. Several fields are incomplete or noisy, so the notebook starts by checking missing values, inconsistent records and unusual metadata patterns.

Some problems are structural rather than cosmetic. For example, paper IDs, author IDs and organizations can be missing. In other cases, different fields may disagree: a note may suggest that a paper belongs to a conference, while the document type says journal. These cases matter because the model later uses venue, document type, authors and citation history as predictive signals.

The preprocessing step therefore normalizes text, years, venues, document types, keywords and author information. Missing metadata is completed where possible by using other available records. Author IDs and organizations are imputed by cross-referencing papers, while keeping the temporal logic of the project in mind: records from the future should not be used to complete records in the past.

## Citation Graph

After cleaning and normalization, the references are used to build a directed citation graph. Each paper is a node, and each citation is an edge from a source paper to a target paper.

The graph is useful for two reasons. First, it gives a direct view of the structure of the dataset: how connected the papers are, how sparse the citation network is, and whether the graph contains meaningful citation paths. Second, it produces features that describe the prior visibility of a target paper, such as in-degree, out-degree, PageRank, betweenness and prior citation count.

These graph features turn out to be important. In the model interpretation, target-side visibility is one of the strongest signals: papers that are already central or frequently cited are more likely to be predicted as citation targets.

## Candidate Pair Generation

The model is trained on source-target pairs. Positive pairs are observed citations. Negative pairs are sampled from plausible target papers that the source did not cite.

This step is important because the model does not compare every paper with every other paper. Instead, it learns from a generated candidate pool. Negative sampling is therefore designed to be realistic: targets are matched by year, venue and popularity bucket, and future targets are excluded. A source paper should not be paired with a target paper that did not exist yet.

This also affects the interpretation of the final predictions. The model ranks candidate targets generated by the pipeline; it does not search the full scientific literature.

## Feature Extraction

The final feature set combines three types of information.

Traditional metadata features describe basic compatibility between source and target, such as publication-year difference, same venue, same document type and number of authors.

Text features measure semantic relatedness between papers, mainly through title and abstract similarity.

Graph features describe the previous visibility of the target paper in the citation graph.

Some possible features were intentionally removed. In particular, bibliography-overlap features such as common references were not used, because they rely on the final reference list of the source paper. That would be valid for a missing-citation detection task, but not for pre-publication citation prediction.

## Feature Selection and Classification

Feature selection shows a clear pattern. The strongest signals are not evenly distributed across all feature groups. Text similarity, especially abstract similarity, carries a large part of the predictive signal. Target-side graph visibility is also highly informative, especially in-degree and prior citation count.

Traditional metadata features contribute less. Features such as shared authors, shared organizations and keyword overlap have weak or nearly zero importance in the selected model.

The final classifier is selected on the validation set. In the current run, the best model is a LightGBM citation-link classifier using the Text + Graph feature set. This is coherent with the feature analysis: the model performs best when it combines semantic similarity between papers with the prior visibility of the target paper.

On the held-out test set, the confusion matrix shows that the model correctly identifies most non-citation pairs and recovers a substantial share of true citation pairs. The main error mode is false positives: pairs that look plausible according to the available features, but are not observed as citations in the test data. For a recommendation-style task, this is not unexpected. Some false positives may still be scientifically reasonable candidates, even if they are not present in the observed bibliography.

## Future Citation Prediction for Year X

The trained citation-link classifier is reused as a scoring model for a specific publication year. For example, for 2024 the notebook selects candidate pairs whose source paper was published in 2024 and assigns each pair a citation probability.

This turns the classifier into a ranking system:

```text
(source paper, candidate target paper) -> probability of citation
```

The year-specific results are strong as a ranking task. For 2024, the model obtains an AUC of 0.8874 within the candidate pool. At rank 1, the top predicted target is an observed citation for about 72% of source papers. At rank 3, the model recovers almost 88% of the observed citations available in the candidate pool. At rank 10, recall reaches 0.9935.

The ranking metrics are more informative than a single binary threshold. Precision decreases as more candidates are recommended, but recall increases quickly. This means the model is especially useful for placing likely citations near the top of a ranked list.

The target-level aggregation also gives an interpretable view of the predictions. The most predicted target papers are often influential or reusable papers, especially in machine learning and computer vision. This matches the model behavior seen in SHAP and feature importance: high scores are driven by semantic similarity and by target visibility in the citation graph.

## Model Interpretation

The interpretation section checks whether the model is relying on reasonable signals.

Feature importance and SHAP values show that the selected LightGBM model mainly uses:

- abstract similarity
- title similarity
- target in-degree
- target citation count
- target PageRank and other graph-centrality features

This is a coherent result for citation prediction. A paper is more likely to cite another paper when the texts are semantically close and when the target paper is already visible in the relevant citation graph.

The PCA plots are used as diagnostics rather than explanations. They show that true positives, true negatives and errors occupy different regions of the candidate-pair feature space. False positives tend to appear near regions where true citations are also found, which suggests that many of them are plausible citation candidates according to the model features.
